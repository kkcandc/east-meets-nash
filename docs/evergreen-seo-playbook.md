# East Meets Nash Evergreen SEO Playbook

Updated: 2026-05-20

## Strategy

East Meets Nash already has a daily news engine. The evergreen layer should capture durable local searches that daily posts will never fully own:

- best East Nashville restaurants
- East Nashville restaurants for kids
- East Nashville patios
- best playgrounds in East Nashville
- East Nashville parks for kids
- things to do in East Nashville this weekend
- East Nashville farmers market
- East Nashville bars with live music
- East Nashville neighborhoods / Five Points / Gallatin / Inglewood guides

Daily posts create freshness. Evergreen guides create compounding search capture.

## Publishing Model

Each guide should be a living page, not a one-time article. The page should include:

- Current updated date.
- Search-intent summary.
- Practical use-case sorting instead of a generic top-ten ranking.
- Source trail with official/business links and local source leads.
- Field-check list for what still needs verification.
- Internal links to related daily stories.
- Clear next refresh trigger: opening, closing, seasonal change, reader tip, or new official source.

## Internal Linking Rules

- Every daily restaurant/opening story should link to the restaurant guide when relevant.
- Every park, family, sidewalk, school, or weekend-plan story should link to the family/playgrounds guide when relevant.
- Topic pages should link into guides once guide cards are added.
- Guide pages should link back to relevant daily stories so freshness flows both ways.

## Google AI Search Rules

Treat AI Overviews and AI Mode as Google Search surfaces. No AI-only hacks. The durable advantage is:

- Googlebot crawlability.
- Sitemap inclusion.
- Snippet eligibility.
- Clear visible content.
- Useful fan-out coverage.
- First-hand local field notes.
- Structured source trails.
- Fresh updates when facts change.

For every guide, add fan-out coverage around adjacent questions. Example for restaurants: parking, kids, patios, reservations, late-night, vegetarian, visitor-safe, and post-show. Example for playgrounds: bathrooms, shade, age range, stroller access, parking, snacks, rainy-day backup, and safety/traffic.
